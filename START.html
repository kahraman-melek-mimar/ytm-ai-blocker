YTM AI Blocker 4.0.11 Beta

by Kahraman MELEK®

Kullanıma hazır, sunucusuz Chrome eklentisi / Ready-to-use, serverless Chrome extension

Türkçe — İlk kurulum

  1. ZIP dosyasını tamamen çıkart. Bu klasörü kalıcı bir yere taşı; yükledikten sonra silme veya taşıma.
  2. Chrome adres çubuğuna chrome://extensions/ yaz.
  3. Sağ üstte Geliştirici modu aç. Paketlenmemiş öğe yükle düğmesine bas.
  4. Bu paketin içindeki extension klasörünü seç. Paketin tamamını seçme.
  5. YouTube Music aç. Chrome araç çubuğundaki yapboz menüsünden YTM AI Blocker'ı sabitle.
  6. Bir parça çalarken eklenti simgesine tıkla; ses analizi başlar. Panelde 4.0.11 Beta görünmeli.

İlk kurulumda otomatik atlama kapalıdır; istersen panelden aç. Sonraki kullanımlarda YouTube Music'i açıp eklenti simgesine tıklaman yeterli. Güncellemede eklentiyi ve YouTube Music sayfasını yenile.

Python, terminal veya yerel sunucu gerekmez. Paket içindeki Python analiz aracı ayrı ve isteğe bağlıdır.

Çift tıklama dosyası açılamazsa doğrudan bu START.html dosyasını aç ve yukarıdaki adımları uygula. Chrome mağaza dışı eklentinin ilk yüklemesini senin yapmanı ister; bu dosya otomatik yükleyici değildir.

English — First setup

  1. Extract the entire ZIP into a permanent folder. Keep the folder after loading the extension.
  2. Enter chrome://extensions/ in Chrome's address bar.
  3. Enable Developer mode and click Load unpacked.
  4. Select this package's extension subfolder.
  5. Open YouTube Music and pin YTM AI Blocker from Chrome's puzzle-piece menu.
  6. Play music and click the extension icon to start audio capture. The panel should show 4.0.11 Beta.

Auto-skip starts off. Enable it in the panel if desired. On later visits, open YouTube Music and click the extension icon. Reload the extension and the music page after updating.

No Python, terminal or local server is required. The optional Python analyzer is separate. If the launcher cannot run, open this START.html file directly. Chrome requires you to load an unpacked extension manually on first use; the launcher does not bypass this step.

Beta: yanlış karar verebilir; DJ ve klasik müzikte önerilmez. / May misclassify music; not recommended for DJ or classical music.
